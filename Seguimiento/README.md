# Seguimiento de dedicación

**Creado:** 05/09/2026 22:11 CEST  
**Última actualización:** 06/09/2026 13:53 CEST

Esta carpeta contiene el registro del tiempo dedicado a POMA para futuros
análisis de esfuerzo y coste.

## Criterio de registro

- Una fila por sesión de trabajo.
- Inicio y fin se anotan en fecha, hora, minuto y zona horaria.
- La duración se expresa en minutos y en horas decimales.
- Se separa trabajo humano, trabajo asistido por agente y esperas externas
  cuando sea posible.
- Las estimaciones o correcciones se identifican expresamente; no se presentan
  como mediciones exactas.

El histórico está en [`registro-horas.md`](./registro-horas.md).
